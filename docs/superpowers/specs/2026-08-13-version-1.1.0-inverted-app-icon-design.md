# Version 1.1.0 and Inverted Application Icon Design

**Date:** 2026-08-13  
**Status:** Approved design; pending written-spec review

## Release Version

Update the canonical application version from `1.0.0` to `1.1.0`.

This is a SemVer minor release because it adds a redesigned compact UI and
extends compatible OneDrive Personal download behavior without intentionally
breaking existing supported workflows.

`Version.props` remains the only canonical source and will contain:

- `Version` = `1.1.0`
- `FileVersion` = `1.1.0.0`
- `AssemblyVersion` = `1.1.0.0`

The UI footer, logs, packaged README, executable metadata, installer metadata,
and artifact names must continue to derive from the canonical version rather
than introducing hard-coded production copies.

Historical specifications that describe the original `1.0.0` release remain
historical records and will not be rewritten. The current OneDrive delivery
plan will be corrected to derive its packaged README version from
`Version.props` instead of naming `1.0.0`.

## Approved Icon Direction

Use the approved inverted **A — Cloud Arrow** mark:

- white rounded-square background;
- black cloud outline;
- black downward arrow centered within the cloud;
- thin black outer border so the white tile remains visible on light Windows
  backgrounds;
- no text, gradients, color accents, transparency-dependent outline, or
  decorative detail.

The geometry must remain recognizable at taskbar and title-bar sizes. Stroke
widths may be optically adjusted per raster size, while the cloud/arrow
silhouette and monochrome palette remain unchanged.

## Icon Generation and Packaging

Update the deterministic repository generator
`scripts/New-AppIcon.ps1`; do not use a manually edited bitmap or an AI image.
The generator will render and package native icon frames at:

`16, 20, 24, 32, 40, 48, 64, 128, 256` pixels.

Every frame uses 32-bit color with alpha-capable edges. The generated
`src/PublicCloudDownloader.App/Assets/PublicCloudDownloader.ico` remains the
single source consumed by:

- WPF `ApplicationIcon` and window/taskbar presentation;
- the published executable;
- the portable release payload;
- installer and uninstall display metadata.

## Verification

Automated checks will establish the expected icon container before replacing
the asset, then verify after generation that:

- the canonical version is exactly `1.1.0` and the file/assembly versions are
  exactly `1.1.0.0`;
- `scripts/version-test.ps1` passes;
- the ICO contains exactly the approved nine dimensions with no duplicates;
- every frame is square and uses 32-bit pixel depth;
- the full Release test suite passes;
- a self-contained Windows x64 publish reports file version `1.1.0.0`;
- the packaged UI displays `Version 1.1.0`, the new icon, and the creator
  attribution without layout regression;
- the packaged self-test and release validation pass.

The corrected payload will replace the executable, README, and icon in
`dist/PublicCloudDownloader` while preserving existing `data` and `logs`
directories.

## Non-Goals

- No product rename or executable rename.
- No breaking workflow or provider changes.
- No installer behavior change beyond consuming version `1.1.0` and the new
  icon.
- No additional color theme, animation, splash screen, or branding text.
